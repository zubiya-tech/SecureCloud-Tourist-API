# SecureCloud Tourist API

Beginner backend infrastructure project built using Flask and Python.

## Project Goal

This project simulates a tourism backend API that provides tourist destination data.

The project is designed to help learn:

- Backend development
- APIs
- JSON responses
- Linux basics
- Cloud concepts
- Docker fundamentals
- Troubleshooting
- Git & GitHub workflow

## Features

- Get all tourist spots
- Filter tourist spots by city
- Health check endpoint
- JSON API responses


## Technologies Used

- Python
- Flask
- Linux (Termux)
- Git & GitHub

# API Endpoints

# Get all tourist spots

/spots

# Get spots by city

/spots/<city>

Example:

/spots/Mumbai

# Health check

/health
