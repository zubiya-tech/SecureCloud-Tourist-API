Tourist Spot Explorer

A Flask and SQLite web application that allows users to search tourist destinations by city.

Features

- Search tourist destinations by city
- View destination details
- Destination images
- SQLite database
- Flask backend
- AWS EC2 deployment
- Security headers
- Rate limiting
- Automatic startup using systemd

Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- AWS EC2
- Git & GitHub

Example Cities

- Agra
- Delhi
- Mumbai

Project Goal

This project was built to learn:

- Backend Development
- Database Integration
- Cloud Deployment
- Linux Server Management
- Git and GitHub

Future Improvements

- More destinations
- More images
- Better UI
- Category filters
- HTTPS support
